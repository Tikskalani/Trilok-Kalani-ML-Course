# Assignment 1 — GitHub Repository Link

The first written assignment for the course. The task was to set up a public GitHub repository for the semester's portfolio work and submit the link in a one-page Word document. This was effectively the "get your tools set up" assignment.

## What I did

- Created a public GitHub account and a portfolio repository for ITAI 1371
- Verified the repo was actually public by opening the link in an incognito browser window (which is what the assignment instructions explicitly called out as a common pitfall to check)
- Submitted the link in the required one-page Word format

## What I learned

Honestly, this was the first time I'd thought of GitHub as something I'd use to *show* my work and not just *store* it. The README on the repo isn't really for me — it's for whoever lands on the page first, which in this case is the instructor. That framing changed how I thought about the rest of the labs and projects throughout the semester. Good READMEs are a habit, not a one-time deliverable.
